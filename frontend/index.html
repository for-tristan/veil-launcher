    Settings

    League of Legends install path
    Detecting…
    Auto-detected from the Windows registry + filesystem. If the path is wrong, install League through the official Riot Client and the launcher will pick it up on next launch.
    Tools directory
    Where Veil looks for the four required binaries: ltk_patcher_host.exe, ltk_patcher_dll.dll, mod-tools.exe, cslol-dll.dll.

    Install LTK Manager (provides ltk_patcher_*) from github.com/LeagueToolkit/ltk-manager/releases — install it, then either let Veil auto-detect it or paste the install path below.

    mod-tools.exe is bundled with Veil. cslol-dll.dll can be compiled from cslol_stub.c (in Veil's resources) or copied from a Rose install.
    Dry Run mode
    When OFF (default), Apply downloads the .fantome, extracts it, runs mod-tools.exe mkoverlay, and spawns ltk_patcher_host.exe which hooks the game on launch. This is the only mode that actually applies skins.

    When ON, Apply skips the ltk_patcher step entirely and falls back to native WAD file modification (experimental, doesn't work against current LoL patches due to ECDSA signature validation).
    Restore all skins
    Walks the League of Legends Game folder and restores every .bak file it finds. Use this before a League patch, or as a panic button if anything goes wrong.
